# WebRock Digital — Presentation

מצגת מוצר מלאה לפלטפורמת WebRock Digital — מערכת AI לניהול שיווק וייעוץ לארגוני שירותים.

## פתיחה

פתח את [`presentation.html`](presentation.html) ישירות בדפדפן — **אין צורך בשרת**.

(`index.html` ו-`WebRock Digital - Presentation.html` מפנים לכאן.)

הקובץ standalone מלא: כל הסקריפטים מוטמעים. בנייד, React/Babel לפאנל Tweaks נטענים רק בדסקטופ (חיסכון זיכרון ב-Safari).

## אינטגרציות מרכזיות

- **cal.com** — קביעת פגישות אוטומטית עם לקוחות (מסך 8 בדמו)
- **Telegram Bot** — אוטומציית משימות: לקוח שולח הודעה → משימה נפתחת אוטומטית
- **Google Gemini** — יצירת דוחות ייעוץ ותוכן שיווקי בעברית
- **Supabase** — Auth + DB + Storage + Edge Functions
